# 🌐 Guía de Internacionalización (i18n)

Para que exista cambio de idioma hay que seguir esta guia

## 1. Configuración del Proyecto
Rails está configurado para cargar archivos de traducción de forma recursiva dentro de subcarpetas en `config/locales/`. 

Si creas una carpeta nueva, **debes reiniciar el servidor** (`rails s`) para que se carguen los nuevos diccionarios.

## 2. Organización de Diccionarios (.yml)
Los archivos se organizan por funcionalidad para evitar archivos gigantes:

```text
config/locales/
├── defaults/          # Textos genéricos (Aceptar, Cancelar,Error)
└── views/             # Textos específicos por cada vista
    └── login/         # Ejemplo: Carpeta para de login
        ├── login.es.yml
        └── login.en.yml
```

## Reglas Críticas del archivo YML:
- Identación: Usa exactamente 2 espacios por nivel. PROHIBIDO usar Tabs.

- Estructura: La primera línea siempre debe ser la clave del idioma (es: o en:).

- Formato: clave: "Texto de la traducción" (siempre usa comillas dobles).

### 3. Uso en las Vistas (HTML.ERB)
Para llamar a una traducción, usamos el helper <%= t('ruta.de.la.clave') %>.

Ejemplo:
Si en config/locales/views/login/login.es.yml tienes:

```
YML
es:
  login:
    title: "Iniciar sesión"
```
En la vista usas:


Code snippet
```
<h1><%= t('login.title') %></h1>
```
